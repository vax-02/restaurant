## 10. Flujo Conversacional del Bot

### 10.1 Flujo del Cliente

#### Paso 1: Inicio del Bot

| Acción | Descripción |
|--------|-------------|
| **Usuario** | El cliente escribe `/start` en el chat con el bot. |
| **Bot** | Consulta la tabla `daily_availability` para obtener los productos disponibles para la fecha actual (`date = CURDATE()`) con `stock > 0`. |
| **Bot** | Muestra el menú del día con los productos, precios y un teclado inline con las opciones de selección. |

#### Paso 2: Selección de Productos y Armado de Pedido

| Acción | Descripción |
|--------|-------------|
| **Usuario** | Selecciona un producto del menú presionando un botón. |
| **Usuario** | Presiona `Agregar` para elegir. |
| **bot** | Pregunta cantidad. |
| **Usuario** | elige cantidad. |
| **Bot** | Valida que la cantidad solicitada no supere el stock disponible en `daily_availability` para la fecha actual. |
| **Bot (stock insuficiente)** | Muestra mensaje de error: "❌ Stock insuficiente. Solo hay [X] unidades disponibles." |
| **Bot (stock suficiente)** | Agrega el producto al carrito temporal |
| **Bot** | Muestra confirmación: "✅ [Producto] agregado al carrito." |
| **Bot** | Muestra opciones: `Agregar más` | `Ver carrito` | `Confirmar pedido` |


#### Paso 4: Generación de QR y Pago

| Acción | Descripción |
|--------|-------------|
| **Bot** | Envía la imagen del QR usando `sendPhoto` de Telegram. |
| **Usuario** | Escanea el QR, realiza el pago y toma una foto del comprobante. |
| **Usuario** | Envía la foto del comprobante al bot. |
| **Bot** | Recibe la imagen y la almacena |
| **Bot** | Pregunta si es Delvery o recogera en el restarunt. |
| **bot (delivery)** | Solicita ubicacion |
| **bot (restauran)** | Confirma pedido |


#### Paso 8: Asignación de Repartidor

| Acción | Descripción |
|--------|-------------|
| **Admin** | En el panel de administración, abre el detalle del pedido. |
| **Admin** | Selecciona un repartidor  |
| **Admin** | Presiona **Asignar repartidor**. |
| **Sistema** | Cambia el estado del pedido |
| **Sistema** | Envía una notificación al repartidor vía Telegram con los detalles del pedido. |
| **Sistema** | Envía notificación al cliente: "🛵 Tu pedido está en camino." |

#### Paso 9: Confirmación del Repartidor (Acuse de Recibo)

| Acción | Descripción |
|--------|-------------|
| **Repartidor** | COmparte ubicacion en tiempo real |
| **Bot** | Envía notificación al cliente: "🛵 El repartidor está en camino." |

#### Paso 12: Confirmación de Entrega

| Acción | Descripción |
|--------|-------------|
| **Repartidor** | Entrega el pedido y presiona el botón **Entregado**. |
| **Bot** | Cambia el estado del pedido |
| **Panel** | Archiva el pedido y lo mueve a "Historial". |

### 10.2 Flujo del Delivery

#### Paso 1: Autenticación del Repartidor

| Acción | Descripción |
|--------|-------------|
| **Repartidor** | Escribe `/start` en el chat con el bot. |
| **Bot** | Verifica si el repartidor ya está autenticado. |
| **Bot (no autenticado)** | Solicita el código de autenticación: "🔑 Ingresa tu código de repartidor." |
| **Repartidor** | Ingresa el código (ejemplo: `DLV-PDSAZ764`). |
| **Bot** | Verifica el código en la tabla `deliveries`. |
| **Bot (código válido)** | Autentica al repartidor, guarda el `chat_id` en `user_telegram`. |
| **Bot** | Muestra el menú de repartidor: `Esperar asignaciones` | `Ver pedidos activos` | `Historial` |
| **Bot (código inválido)** | Muestra mensaje de error: "❌ Código inválido. Intenta nuevamente." |

#### Paso 4: Seguimiento en Tiempo Real (Delivery)

| Acción | Descripción |
|--------|-------------|
| **Repartidor** | Comparte su ubicación en vivo usando la función de Telegram. |
| **Bot** | Recibe actualizaciones periódicas de ubicación. |
| **Bot** | Almacena las ubicaciones en la tabla `ubicaciones_delivery`. |
| **Panel** | Muestra la ubicación del repartidor en el mapa en tiempo real. |

#### Paso 5: Confirmación de  Entrega

| Acción | Descripción |
|--------|-------------|
| **Repartidor** | Entrega el pedido y presiona **Entregado**. |
| **Bot** | Cambia el estado del pedido  |

### 10.4 Resumen de Comandos del Bot

| Comando | Rol | Descripción |
|---------|-----|-------------|
| `/start` | Cliente / Delivery | Inicia el bot y muestra menú según rol. |
| `/menu` | Cliente | Muestra el menú del día. |
| `/cancelar` | Cliente | Cancela el pedido en curso. |
| `/delivery` | delivery | Brinda codigo al bot para ser considerado como deliver en asignaciones. |
| `/ayuda` | Cliente / Delivery | Muestra los comandos disponibles. |

## 13. Manual de Usuario - Administrador

### 13.1 Iniciar sesión

1. Abre el panel web 
2. Ingresa tu **usuario** y **contraseña**.
3. Presiona **Iniciar sesión**.

### 13.2 Gestionar productos

**Menú → Productos**

| Acción | Descripción |
|--------|-------------|
| **Ver lista** | Muestra todos los productos del menú con su nombre, descripción, precio, categoría y disponibilidad. |
| **Crear producto** | Ingresa nombre, descripción, precio y categoría (plato/bebida). Presiona **Guardar**. |
| **Editar producto** | Modifica los datos de un producto existente. Presiona **Actualizar**. |
| **Eliminar producto** | Elimina un producto del menú. El producto desaparecerá del bot. |
| **Ver/ocultar producto** | Cambia el estado `available` para mostrar u ocultar el producto sin eliminarlo. |

### 13.3 Gestionar stock diario

**Menú → Stock Diario**

| Acción | Descripción |
|--------|-------------|
| **Ver stock** | Muestra el stock de cada producto para la fecha seleccionada. |
| **Configurar stock** | Define cuántas unidades hay disponibles de cada producto para una fecha específica. |
| **Actualizar stock** | Modifica el stock de un producto para una fecha específica. |
| **Stock automático** | Al confirmar un pago, el stock se descuenta automáticamente. |

### 13.4 Gestionar pedidos

**Pedidos → Tablero**

| Acción | Descripción |
|--------|-------------|
| **Ver todos los pedidos** | Tabla con todos los pedidos, estado y fecha. |
| **Filtrar pedidos** | Filtra por estado, fecha o cliente. |
| **Ver detalle** | Muestra comprobante, productos, total y ubicación. |
| **Cambiar estado** | Confirma, prepara, cancela pedidos desde el detalle. |

### 13.5 Aceptar pagos

1. Abre el detalle de un pedido en **Pedidos → Tablero**.
2. En la sección de **Comprobante**, verás la imagen enviada por el cliente.
3. Verifica que el comprobante sea válido (monto, fecha, referencia).
4. Presiona **Asignar delivery**.
5. El stock se descuenta automáticamente
6. El cliente recibe una notificación: "

**Rechazar pago:**
1. Presiona **Rechazar pago**.
2. Ingresa un motivo en el campo `cancel_reason`.
3. El cliente recibe la notificación: "❌ Tu pago no pudo ser confirmado. Motivo: [razón]."

### 13.6 Asignar repartidores

1. Abre el detalle de un pedido en **Pedidos → Tablero**.
2. Ve a la sección **Asignar repartidor**.
3. Selecciona un repartidor del desplegable.
4. Presiona **Asignar repartidor**.
5. El repartidor recibe una notificación en Telegram con los detalles del pedido.
6. El cliente recibe la notificación: "🛵 Tu pedido está en camino."

**Reasignar repartidor:**
1. Abre el detalle del pedido.
2. Selecciona un nuevo repartidor del desplegable.
3. Presiona **Reasignar repartidor**.
4. El repartidor anterior recibe la notificación: "⚠️ El pedido #X ha sido reasignado."
5. El nuevo repartidor recibe la notificación completa del pedido.

### 13.8 Gestionar repartidores

**Configuración → Repartidores**

| Acción | Descripción |
|--------|-------------|
| **Ver lista** | Muestra todos los repartidores registrados con su código, nombre, apellido, teléfono y estado. |
| **Crear repartidor** | Ingresa nombre, apellido, teléfono. El sistema genera un código único automáticamente. |
| **Editar repartidor** | Modifica los datos de un repartidor existente. |
| **Eliminar repartidor** | Elimina un repartidor del sistema. |
| **Ver código** | Muestra el código de autenticación del repartidor para entregárselo. |
| **Activar/desactivar** | Cambia el `status` del repartidor (1 = activo, 0 = inactivo). |


### 13.10 Generar reportes

**Reportes**

| Reporte | Descripción |
|---------|-------------|
| **Ventas del día** | Muestra el total de ventas del día actual con desglose por pedido. |
| **Ventas por fecha** | Permite seleccionar un rango de fechas para ver las ventas. |
| **Productos más pedidos** | Muestra los productos más solicitados con su cantidad total y porcentaje. |
| **Tiempo promedio de entrega** | Calcula el tiempo promedio desde "confirmado" hasta "entregado". |
| **Clientes frecuentes** | Muestra los clientes con mayor cantidad de pedidos. |

### 13.11 Gestionar usuarios del panel

**Configuración → Usuarios**

| Acción | Descripción |
|--------|-------------|
| **Ver lista** | Muestra todos los usuarios del panel (admin y ayudantes). |
| **Crear usuario** | Ingresa nombre, email, rol (admin/ayudante) y contraseña. |
| **Editar usuario** | Modifica los datos de un usuario existente. |
| **Eliminar usuario** | Elimina un usuario del panel. |
| **Cambiar rol** | Cambia el rol de un usuario entre admin y ayudante. |

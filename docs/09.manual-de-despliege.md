## 14. Manual de Despliegue

### 14.1 Requisitos del Sistema

| Componente | Requisito | Versión mínima |
|------------|-----------|----------------|
| **PHP** | Servidor web con PHP | 8.2+ |
| **MySQL / MariaDB** | Base de datos | MySQL 8.0+ / MariaDB 10.4+ |
| **Composer** | Gestor de dependencias de PHP | 2.0+ |
| **Git** | Sistema de control de versiones | 2.20+ |
| **Web Server** | Apache / Nginx | - |
| **Node.js** | Para assets (opcional) | 16+ |

### 14.2 Instalación PASO a PASO

git clone ---nombre de la repo

cd -- nombre de la carpeta

configurar el archivo .env en base a su .env.example importante poner el api de telegram

php artisan key:generate

php artisan migrate

Sirve crear usuarios 
php artisan db:seed --class=UsersTableSeeder 

php artisan db:seed --class=ProductSeeder    (opcional es para productos)


npm install
npm run build

composer install

php artisan serve
